# 平凯数据库（TiDB 企业版）与 TiDB 社区版功能差异

> **背景**：平凯数据库（TiDB 企业版）是平凯星辰公司基于 TiDB 开源内核深度优化与企业级功能增强的商业版本，已通过国家分布式数据库安全可靠测评及信通院 HTAP 数据库基础能力评测。
>
> **版本**：平凯数据库 v7.1.9（基于 TiDB v8.5 LTS 内核）
>
> **适用范围**：当用户询问企业版特性、两个版本的区别、License、选型建议时使用本 Skill。

---

## 一、企业版独有功能（社区版不支持）

以下功能为平凯数据库企业版专有，TiDB 社区版不包含：

### 1. 企业级内核增强

| 功能 | 说明 | 社区版 |
|------|------|--------|
| **GB18030-2022 字符集** | 国家标准字符集，支持更多汉字和符号 | ❌ 不支持 |
| **存储过程（兼容 MySQL 语法）** | 企业版支持在数据库侧执行业务逻辑，减少应用层代码 | ❌ 不支持 |
| **审计日志（Audit Log）** | 记录所有 SQL 操作，支持过滤、告警和合规审计 | ❌ 不支持 |
| **全链路 mTLS** | 组件间双向 TLS 加密通信，提升整体安全性 | ❌ 不支持 |

### 2. 企业级工具

| 功能 | 说明 | 社区版 |
|------|------|--------|
| **TEM 企业级运维管理平台** | 统一集群管理、监控、告警、运维操作界面 | ❌ 不支持 |
| **TMS 企业级异构迁移平台** | 支持复杂迁移场景，Oracle/SQL Server 等异构数据库迁移 | ❌ 不支持 |

### 3. 部署模式与架构

| 项目 | 企业版 | 社区版 |
|------|--------|--------|
| 敏捷模式（1-3 节点起步） | ✅ 支持 | ❌ 不支持 |
| 两节点 + 仲裁部署 | ✅ 支持（高可用降成本） | ❌ 不支持 |
| LoongArch（龙芯）架构 | ✅ 支持 | ❌ 不支持 |
| 国产操作系统（OpenEuler/Kylin/UOS） | ✅ 支持 | ❌ 部分支持 |
| ARM 架构 | ✅ 完整支持 | ❌ 部分支持 |

### 4. 企业级支持服务

| 服务项目 | 企业版 | 社区版 |
|----------|--------|--------|
| 400 电话 / 工单 / 邮件支持 | ✅ | ❌ |
| 研发支持（24 小时在线响应） | ✅ | ❌ |
| 现场技术专家服务 | ✅ | ❌ |
| 原厂专家交付服务 | ✅ | ❌ |
| 技术认证考试 | ✅ | ❌（论坛自学） |
| 发行版支持服务 | ✅ | ❌ |
| 数据库开发支持服务 | ✅ | ❌ |

## 二、社区版也支持的基础功能（共同能力）

以下为两个版本均支持的功能，社区用户无需额外授权即可使用：

| 类别 | 功能 |
|------|------|
| **部署工具** | TiUP Cluster / TiDB Operator |
| **数据迁移** | DM / Dumpling / Lightning / TiCDC / BR / sync-diff-inspector |
| **内核** | tidb-server / tikv-server / tiflash-server / pd-server |
| **SQL** | CTE / 窗口函数 / JSON / 表达式索引 / 执行计划绑定 |
| **事务** | 悲观事务 / 乐观事务 / 1PC / Async Commit |
| **分区** | Range / Hash / List / Key 分区，动态裁剪 |
| **安全** | TLS / TDE / RBAC / 密码管理 / LDAP 认证 |
| **备份恢复** | BR / PITR / 基于 EBS 的备份恢复 |
| **资源管控** | RU（Request Unit）资源管控 |
| **工具平台** | TiDB Dashboard / Grafana / Top SQL / 慢查询日志 |

## 三、平凯数据库 v7.1.9 新增企业特性（相对于 TiDB 内核）

以下为企业版在 v7.1.9 版本引入的新特性：

### 3.1 MySQL 兼容性增强（Beta）

- **触发器（Trigger）**：支持在 INSERT/UPDATE/DELETE 事件上定义自动执行逻辑，适用于数据校验、审计记录及业务规则下沉
- **用户自定义函数（UDF）**：支持扩展数据库计算能力，支持在数据库侧执行复杂业务逻辑

> ⚠️ 注意：触发器与 UDF 当前为 Beta 能力，建议生产使用前充分验证。

### 3.2 敏捷模式增强

- **两节点 + 仲裁部署**：在资源受限场景下提供高可用能力，显著降低硬件门槛，基于 Raft 保障数据一致性

### 3.3 数据安全与访问控制

| 功能 | 说明 |
|------|------|
| **表级与列级加密** | 数据静态加密，满足敏感数据保护与合规要求 |
| **LBAC（Label-based Access Control）** | 基于标签的细粒度访问控制，支持多级安全策略 |
| **客户端 IP 黑白名单** | 支持 CIDR 格式，黑名单优先匹配 |
| **登录历史记录** | `mysql.login_history` 表记录登录成功/失败信息 |

### 3.4 SQL 与系统能力

| 功能 | 说明 |
|------|------|
| **事务内动态修改隔离级别** | 悲观事务下支持在 REPEATABLE READ 与 READ COMMITTED 之间切换，无需结束事务 |
| **ARRAY 数据类型** | 原生数组支持 |
| **XML 数据类型** | 支持 XML 类型及 `EXTRACTVALUE()` 函数 |
| **INTERVAL 数据类型** | 日期时间间隔计算增强 |

### 3.5 运维与管控

- **TEM 企业级管控平台**：统一集群管理、监控与运维，支持数据库全生命周期管理

## 四、TiDB 社区版 vs 平凯数据库选型建议

### 选社区版的场景

- 开源技术探索、教学、研发测试
- 无企业级支持需求
- 自主运维能力强，有 DBA 团队
- 不需要存储过程、审计日志、TEM/TMS 等企业工具
- 预算有限

### 选企业版的场景

- 生产环境，需要 7×24 原厂支持
- 有国产化、信创合规要求（GB18030、国产 OS、LoongArch）
- 需要存储过程、审计日志、数据加密等企业安全特性
- 需要 TEM/TMS 企业工具降低运维复杂度
- 需要 Oracle/SQL Server 等异构数据库迁移支持
- 需要现场专家服务和认证培训

## 五、License 管理说明

平凯数据库企业版需要 License 授权：

| 项目 | 说明 |
|------|------|
| 获取 License | 联系平凯星辰商务获取 |
| 激活 | 在敏捷模式集群中通过 TEM 或命令行激活 |
| 更新 License | 支持在线更新 |
| 过期限制 | License 过期后部分企业功能受限，核心数据库功能仍可用 |
